# Project Summary

This project presents a simulation and analysis environment for quantum key distribution (QKD), with a focus on the BB84 protocol and its post-processing stages. The work studies how a raw quantum key can be converted into a secure final key when the channel is noisy or when an eavesdropper may be present. The main purpose is to compare practical post-processing methods and to measure how they behave under different levels of quantum bit error rate (QBER), block size, distance, and mean photon number. In simple terms, the project asks how secure key generation changes when the physical channel and the classical post-processing step are both imperfect.

At a high level, the project follows the standard BB84 workflow. Alice prepares and sends quantum states through a simulated optical channel, Bob receives them with detector noise and channel errors, and both parties then perform classical post-processing. The post-processing stage includes sifting, error correction, and privacy amplification. The study tests several reconciliation protocols, including Cascade, Winnow, standard LDPC, rate-adaptive LDPC, and Polar codes. It also includes privacy amplification methods such as Toeplitz hashing and SHAKE256-based hashing. The core research question is which post-processing pipeline gives the best balance between security, efficiency, latency, and computational cost.

The implementation combines end-to-end simulations, result collection, and visual analysis. A separate post-processing toolbox is included, and it is designed to be independent of any single QKD protocol. This toolbox contains reusable logic for reconciliation and privacy amplification, so it can support multiple simulation settings and application styles. The overall structure separates the physical channel model, the classical post-processing algorithms, and the visualization layer.

The figures show the main experimental outcomes. The error-correction results compare five reconciliation protocols across QBER values. The key leakage graph shows that leakage increases with QBER for all methods, but the growth rate is protocol dependent. LDPC has the highest leakage in the tested range, while Cascade leaks less and remains more stable. Winnow and rate-adaptive LDPC lie in between, and Polar codes often appear more efficient than the other interactive methods at higher QBER values. This is important because a protocol can be secure in principle but still expensive in revealed information, which directly reduces the final secure key rate.

The efficiency plot gives a complementary view. It estimates reconciliation inefficiency relative to the Shannon limit. Values close to 1 are better because they mean the protocol is using nearly the minimum theoretical amount of information for error correction. In the plotted results, Cascade and Polar codes are closer to the ideal boundary than LDPC, while Winnow and rate-adaptive LDPC sit in the middle. The LDPC curve rises strongly with QBER, showing the sensitivity of fixed-rate coding schemes to channel conditions.

The latency plot measures the number of channel uses or round trips. It shows that interactive protocols differ strongly in communication cost. LDPC requires the fewest round trips because it is largely one-way once the syndrome exchange begins. Winnow stays low, but still needs more interaction than LDPC. Cascade needs many more round trips, which is expected because it uses multiple passes and binary searches to locate errors. Polar codes have the highest communication cost, reflecting the larger amount of structured interaction and decoding overhead.

The block-size scalability plot shows how long each protocol takes to process larger keys. In these results, the LDPC-based methods are slower than the others, especially the rate-adaptive version, which suggests higher algorithmic complexity and stronger dependence on decoding operations. Cascade, Winnow, and Polar codes scale more smoothly in the tested range. This matters because practical QKD systems must process large blocks quickly enough to keep up with the quantum layer.

The secure key rate graph combines leakage and reconciliation efficiency into a single performance view. It shows that the final secret key rate decreases as QBER increases, which is expected because more noise leaves less extractable secrecy. Cascade and Polar codes remain usable over a wider range of error rates, while LDPC drops most quickly and can become negative sooner. Winnow and rate-adaptive LDPC perform better than standard LDPC but still degrade steadily with increasing noise.

The distance and mean-photon-number plots extend the analysis beyond the protocol comparison. They show secret key rate as a function of distance and mean photon number, which are two core physical parameters in QKD. The distance graphs show the expected decay of secret key rate as channel loss accumulates. The finite BB84 curves stay above the asymptotic reference only in the short-distance, low-loss regime, and all methods eventually fall toward zero as distance increases. This confirms the physical limit that long fiber links reduce detectable signal strength and increase the relative impact of noise.

Taken together, the figures support a coherent experimental narrative. The latency plots highlight the cost of interaction, the leakage plots show how much information each protocol reveals, the efficiency plots quantify closeness to the Shannon limit, and the runtime plots measure growth with block size. The remaining SKR figures, including the distance and mean-photon plots, connect those protocol-level costs to the final system-level outcome. This is the main scientific strength of the project: it links implementation choices to physical performance in a way that is directly useful for QKD design.

The mean-photon-number plots show a clear peak at small nonzero values of $\mu$. Very low $\mu$ does not send enough photons, while very high $\mu$ increases multi-photon risk and reduces the secure rate. The graphs therefore show an optimal operating window rather than a monotonic improvement. This reflects the central BB84 trade-off between detection probability and security.


Overall, the project demonstrates a complete BB84 post-processing research environment. It does not only generate keys; it measures how different algorithms transform raw quantum data into final secure keys under realistic constraints. The figures show the main scientific conclusions. No single protocol is best in every regime, so the best choice depends on noise level, speed, leakage tolerance, and implementation setting.

For research use, this means the project can support comparative studies, parameter sweeps, and protocol selection for different channel conditions. For engineering use, it gives a clear view of which parts of the QKD pipeline dominate cost and which parts are likely to limit performance. The overall message from the figures is consistent: secure QKD is possible only when reconciliation and privacy amplification are matched carefully to the channel noise and to the desired operating distance.
